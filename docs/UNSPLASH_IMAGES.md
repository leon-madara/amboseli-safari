All images should be:
1. **Downloaded and optimized** before production
2. **Converted to WebP/AVIF** for better compression
3. **Sized appropriately**:
   - Background: 2400px wide
   - Foreground: 1920px wide
   - Thumbnails: 800px wide
4. **Compressed** to < 500KB each for fast loading
